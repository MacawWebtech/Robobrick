# Image credits

All images used by the template are stored locally in `assets/img/`. No page loads photos from a third-party CDN (Unsplash, Pexels or similar).

To swap a photo, replace the file in `assets/img/` (keep the same file name) or point the `src` attribute to your own file. Each `<img>` also has a `data-fallback` SVG illustration that is shown if a photo file is missing.

Make sure you own, or have a licence for, every photo you ship, and have written consent from parents before publishing photos of real children.
