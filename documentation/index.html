RoboBricks documentation

Thanks for choosing RoboBricks, a multipage HTML template for kids' robotics, LEGO engineering and coding clubs, with a full parent dashboard. This guide covers setup, customisation and every interactive feature.

Installation

No build step. Upload the folder to any web host, or preview locally with a static server:

npx serve .
# or
python3 -m http.server 8000

Bootstrap 5.3, Bootstrap Icons and Google Fonts load from CDNs. To self-host, download them, replace the URLs in each page's <head>, and update BS_LTR / BS_RTL at the top of assets/js/main.js.

Opening files directly with file:// works, but some browsers restrict localStorage there. Use a local server to test theme and RTL persistence.

Colours & fonts

Every colour, radius and shadow is a CSS custom property at the top of assets/css/style.css. Change a value once and it updates across all 32 pages.

--rb-navy#0A0A0A
--rb-blue#0A0A0A
--rb-yellow#FACC15
--rb-orange#FACC15
--rb-mint#FACC15
--rb-sky#FFFFFF
--rb-white#FFFFFF
--rb-gray#4E4E4E
:root {
  --rb-yellow: #FACC15;   /* primary CTA */
  --rb-blue:   #0A0A0A;   /* black: secondary buttons (yellow in dark mode) */
  --rb-shadow: 4px 4px 0 var(--rb-line);  /* brick shadow; set to none to soften */
  --rb-font-display: "Nunito", system-ui, sans-serif;
}

Dark mode values are in the [data-bs-theme="dark"] block directly below :root. Fonts: Nunito for headings, Manrope for body text, Space Grotesk for small technical labels. To swap fonts, update the three --rb-font-* tokens and the Google Fonts URL.

JavaScript hooks

Interactive behaviour is attached through data attributes, so you can reuse any feature on any page without touching JavaScript.

AttributeWhat it does
data-revealFades the element in when it scrolls into view.
data-count="1800" data-suffix="+"Animated number counter.
data-progress="78"Animates a bar's width to 78%.
data-ring="78"Animates a .ring progress circle.
data-finderProgram finder. Edit the PROGRAMS array in main.js.
data-filter-group="#id"Filter buttons for children of #id with data-cat.
data-faq-searchLive FAQ search with highlighting.
form[data-validate]Validation; data-success sets the toast, data-redirect navigates.
data-lightbox="file.svg"Opens an image in the gallery modal.
data-countdown="ISO date"Live event countdown.
data-toast="Message"Shows a toast on click.
data-theme-toggle / data-dir-toggleTurns any button into a theme or direction switch.
data-calendarDashboard calendar; sessions live in SESSIONS in dashboard.js.
data-messagesDashboard chat behaviour.
data-table-search="#table"Live table filter.

Show a toast from your own scripts with window.RoboBricks.toast("Saved").

Dark mode & RTL

Both preferences are saved in localStorage and applied by a tiny inline script before the page renders, so there's no flash of the wrong theme.

KeyValuesToggle
robotics-themelight / darkdata-theme-toggle
robotics-dirltr / rtldata-dir-toggle

To make RTL the default for an Arabic or Hebrew site, set <html lang="ar" dir="rtl"> and point the #bs-css link at bootstrap.rtl.min.css. Layout uses CSS logical properties, so sidebars, timelines, progress bars and forms mirror automatically.

With the English demo copy, RTL shows punctuation at the start of headings. This disappears once you add real right-to-left text.

Forms

Contact, login, register, enrollment and dashboard forms validate in the browser and show a success toast. To send data to your server, replace the setTimeout inside the form[data-validate] handler in main.js:

const res = await fetch(form.action, { method: "POST", body: new FormData(form) });
if (!res.ok) { toast("Something went wrong. Try again.", "bi-exclamation-circle-fill"); return; }
toast(form.dataset.success);

Replacing images

The demo uses real photos from Pexels and Unsplash (free for commercial use, credited in CREDITS.md). They're hotlinked from the providers' CDNs rather than bundled, because both licences forbid redistributing the files inside a product. Each image carries a data-fallback SVG, and main.js swaps it in automatically if the photo can't load.

<img src="../assets/img/club-hero.jpg"
     data-fallback="../assets/img/hero-makerspace.svg"
     alt="Kids building a rover at Saturday class" width="1600" height="1400">

For a live site, use your own club photos or download and self-host the demo photos. Keep the width/height attributes for layout stability. Recommended sizes:

Always get written parent consent before publishing photos of your own students.

SEO & accessibility

  • Replace https://robobricks.example.com with your domain in canonical, Open Graph and JSON-LD tags (one search-and-replace).
  • Structured data included: EducationalOrganization, Course, Event, Article, FAQPage, BreadcrumbList.
  • One <h1> per page, landmark regions, skip link, visible focus outlines and keyboard-operable tabs.
  • Filters, FAQ search and toasts announce changes through ARIA live regions.
  • Animations respect prefers-reduced-motion.
  • Dashboard pages carry noindex, nofollow.
